# Créditos de las fotografías

Descargadas de Unsplash bajo la Licencia Unsplash, que permite el uso comercial y no comercial
sin permiso previo. Ninguna es Unsplash+ / Getty: el script que las bajó rechaza las marcadas
como `plus`, porque esas requieren suscripción paga y no se pueden versionar en este repo.

Para reemplazarlas por fotos reales del centro, sustituir el archivo manteniendo el nombre y
la relación de aspecto.
