## Trabajo Práctico Final

Un SaaS de turnos para centros de estética: cada centro publica su agenda, cobra señas con
Mercado Pago en su propia cuenta y gestiona sus turnos desde un panel. Lo hicimos en grupo:

- **Rodrigo Hernández** — backend (NestJS, Prisma, Postgres) y la integración con Mercado Pago.
- **Matías Alfaro** — frontend (Next.js).

Está desplegado: el sitio en [pasate.vercel.app](https://pasate.vercel.app/) y la API en
[hernandez-iisaia.onrender.com/api/v1](https://hernandez-iisaia.onrender.com/api/v1/docs).
El informe, con cómo se ejecuta y cómo lo construimos, está en [tp-final/README.md](tp-final/README.md).
